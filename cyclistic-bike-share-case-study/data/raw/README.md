# Raw data

Raw trip data is **not** committed to this repository (too large for GitHub, and excluded via
`.gitignore`). To reproduce this analysis:

1. Download the last 12 months of Cyclistic (Divvy) trip data from the public dataset:
   https://divvy-tripdata.s3.amazonaws.com/index.html
2. Unzip the monthly `.csv` files into this folder (`data/raw/`).

The data is made available by Motivate International Inc. under this
[license](https://divvybikes.com/data-license-agreement). It has been anonymized — there is no
personally identifiable information, so it is not possible to link casual riders to purchase
history or determine whether they live in the service area.
